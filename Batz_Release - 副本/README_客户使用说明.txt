=========================================================
巴兹汽车 支架生产系统信息看板 - 部署启动说明
=========================================================

一、目录结构说明
------------------
- dist/              (大屏端前端静态文件)
- admin/dist/        (管理后台前端静态文件)
- batz-backend.exe   (核心数据服务程序)
- .env               (数据库连接配置文件，需手动创建或补充)


二、启动步骤
------------------
1. 确保本目录下存在 `.env` 文件，并正确配置了 SQL Server 的连接信息。
   格式如下：
   DB_USER=sa
   DB_PASSWORD=Ks123456
   DB_SERVER=127.0.0.1
   DB_NAME=BatzPlcData
   PORT=3001

2. 双击运行 `batz-backend.exe`。
   (运行后会弹出一个黑色命令行窗口，请保持该窗口打开，不要关闭它。关闭即代表服务停止。)

3. 服务启动成功后，在浏览器中访问：
   - 数据大屏地址：http://localhost:3001
   - 管理后台地址：http://localhost:3001/admin

   如果需要在局域网其他电脑访问，请将 localhost 替换为这台服务器的局域网 IP 地址。
