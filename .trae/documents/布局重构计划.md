# 页面布局重构方案 (Layout Refactoring Plan)

## 1. 需求分析
用户希望重新调整主界面的模块布局，以适应新的视觉需求。

### 当前布局 (Current)
目前尚未明确具体的 CSS Grid 结构，但通常是上下分层或左右分栏。

### 目标布局 (Target)
- **左侧区域 (Left Column)**:
  - **上部**: 注塑模块 (InjectionModule)
  - **下部**: 质量趋势与缺陷分析 (QualityModule)
  - **排列方式**: 垂直排列 (Vertical Stack)

- **右侧区域 (Right Column)**:
  - **全高**: 组装模块 (AssemblyModule)
  - **排列方式**: 占据右侧全部高度，内部可能需要调整为垂直布局以适应新的长宽比。

---

## 2. 实施计划 (Implementation Plan)

### 2.1 容器结构调整 (`src/App.jsx` 或主布局文件)
我们将使用 CSS Grid 或 Flexbox 来实现左右分栏布局。

```jsx
<div className="flex h-screen p-4 gap-4 bg-gray-900">
  {/* Left Column - 40% Width */}
  <div className="w-[40%] flex flex-col gap-4">
    <div className="flex-1">
      <InjectionModule />
    </div>
    <div className="flex-1">
      <QualityModule />
    </div>
  </div>

  {/* Right Column - 60% Width */}
  <div className="flex-1">
    <AssemblyModule />
  </div>
</div>
```

### 2.2 模块内部适配
由于容器尺寸发生变化，各模块内部的图表可能需要自适应调整。

- **InjectionModule & QualityModule**:
  - 原本可能是横向铺开的，现在变为占据左侧一半高度，宽高比变化不大，预计无需大幅修改，ECharts 会自动 resize。

- **AssemblyModule (组装模块)**:
  - 原本是横向排列的三个子模块 (OP10, OP20, OP30)。
  - **挑战**: 如果右侧区域变窄（或者变得很高），原本横向并排的三个卡片可能需要改为 **垂直排列** (Top-to-Bottom) 或者 **网格排列** (2行)，以充分利用垂直空间。
  - **建议**: 将 AssemblyModule 内部布局改为垂直 Flex (`flex-col`)，让 OP10, OP20, OP30 从上到下依次排列，每个占据 1/3 高度。

### 2.3 响应式处理
确保在不同分辨率下，布局不会崩坏（主要针对 1920x1080 大屏优化）。
