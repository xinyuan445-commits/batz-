# SQL Server 数据库集成与实时数据看板计划

本计划旨在将现有的 React 生产数据看板与 SQL Server 数据库 (`BATZPlcData`) 进行对接，实现数据的实时展示。

## 1. 后端服务搭建 (Node.js + Express)

为了安全地连接数据库并为前端提供 API，我们将搭建一个轻量级的中间层服务。

- [ ] **初始化后端项目**
    - 在项目根目录下创建 `server` 目录。
    - 初始化 `package.json`。
    - 安装必要依赖：`express` (Web 服务), `mssql` (SQL Server 驱动), `cors` (跨域处理), `dotenv` (环境变量管理), `nodemon` (开发热重载)。

- [ ] **配置数据库连接**
    - 创建数据库配置文件，使用提供的凭据：
        - **Host**: localhost (假设数据库在本地，如果不是请提供 IP)
        - **User**: sa
        - **Password**: Ks123456
        - **Database**: BATZPlcData
    - 实现连接池 (`ConnectionPool`) 以优化性能。

- [ ] **创建基础 API 服务器**
    - 搭建 Express 服务器，监听指定端口 (如 3001)。
    - 配置 CORS 以允许前端 (localhost:5566) 访问。
    - 编写一个测试接口 `/api/health` 验证服务器状态。
    - 编写一个数据库测试接口 `/api/test-db`，执行简单的 `SELECT 1` 或查询系统表，验证数据库连接是否成功。

## 2. 业务数据接口开发 (等待表结构信息)

一旦数据库连接成功，我们将根据您提供的表结构和字段信息开发具体的业务接口。

- [ ] **接收表结构信息**
    - 等待用户提供具体的表名、字段定义以及各指标（KPI、注塑、质量、组装）对应的数据来源。

- [ ] **实现数据查询接口**
    - **KPI 接口**: 获取产量、合格率、OEE 等核心指标。
    - **注塑数据接口**: 获取注塑机的实时参数和历史趋势。
    - **质量数据接口**: 获取质量检测数据和不良品分布。
    - **组装线接口**: 获取各工位的实时物理数据（位移、压力等）。

## 3. 前端对接与实时刷新

- [ ] **配置 API 代理 (Vite)**
    - 在 `vite.config.js` 中配置代理，将 `/api` 请求转发到后端服务器 (localhost:3001)，解决跨域问题并简化调用。

- [ ] **组件数据接入**
    - 改造现有的 UI 组件 (`KPIGauges.jsx`, `InjectionModule.jsx` 等)。
    - 使用 `useEffect` 和 `fetch` 替换静态硬编码数据。
    - 实现轮询机制 (如每 3-5 秒刷新一次)，确保数据实时性。
    - 添加加载状态 (Loading) 和错误处理 (Error Handling) UI。

## 4. 验证与调试

- [ ] **联调测试**
    - 启动后端服务和前端应用。
    - 验证数据是否能正确从数据库流向前端页面。
    - 检查控制台是否有报错，确保连接稳定。
