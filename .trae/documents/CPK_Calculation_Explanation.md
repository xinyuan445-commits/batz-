# Batz 生产数据看板 - CPK 计算原理说明

本文档旨在解释系统内部如何计算 CPK（过程能力指数），以便于向客户说明数据来源及计算逻辑。

## 1. 什么是 CPK？
CPK (Process Capability Index) 是**过程能力指数**，用于衡量生产过程在受控状态下，产出符合规格要求产品的能力。它同时考虑了过程的**离散程度**（波动）和**偏移程度**（中心值与目标值的偏差）。

简单来说：**CPK 值越大，说明生产过程越稳定，产品质量越好。**

## 2. 系统计算逻辑

本系统采用标准的 CPK 计算公式，基于**实时采集的最近 20 个样本数据**进行动态计算。

### 2.1 基础公式
$$CPK = \min(CPU, CPL)$$

其中：
- **CPU** (Upper Capability Index) = 上规格限能力指数
- **CPL** (Lower Capability Index) = 下规格限能力指数

### 2.2 详细计算步骤

**第一步：计算平均值 ($\mu$) 和 标准差 ($\sigma$)**
系统获取最近生产的 $N$ 个产品数据（$N \le 20$）：
- **平均值 ($\mu$)**：所有数据的算术平均。
- **标准差 ($\sigma$)**：采用**样本标准差**公式（除以 $n-1$），反映数据的波动大小。
  $$ \sigma = \sqrt{\frac{\sum(x_i - \mu)^2}{n-1}} $$

**第二步：计算单侧能力指数**
- **$CPU = \frac{USL - \mu}{3\sigma}$**
  （$USL$ = 规格上限）
  
- **$CPL = \frac{\mu - LSL}{3\sigma}$**
  （$LSL$ = 规格下限）

**第三步：取最小值**
- $CPK = \min(CPU, CPL)$

> **注意**：
> 1. 如果数据样本少于 5 个，系统不进行计算（显示为 `-`）。
> 2. 如果标准差为 0（所有数据完全一样），系统判定为完美一致，显示默认高值 `9.99`。

## 3. 判定标准与颜色说明

系统根据计算出的 CPK 数值，自动标记颜色以提示过程状态：

| CPK 数值范围 | 颜色 | 含义说明 | 客户解释话术 |
| :--- | :--- | :--- | :--- |
| **CPK $\ge$ 1.33** | 🟢 **绿色** | **过程能力充分** | 生产非常稳定，产品尺寸波动很小，完全满足质量要求。 |
| **1.0 $\le$ CPK < 1.33** | 🟡 **黄色** | **过程能力尚可** | 生产质量合格，但波动稍大，接近临界点，建议关注。 |
| **CPK < 1.0** | 🔴 **红色** | **过程能力不足** | 生产波动过大或中心值偏移严重，存在产生不良品的风险，需要立即调整设备。 |
